# Repository map

## What this is

Public distribution repository for **Kizu Engineering Partner**, a single Markdown skill for AI coding agents. The product is `SKILL.md`; everything else packages, explains or publishes it.

## Canonical content

- `SKILL.md` is the only source of the skill. Edit it here, never in generated output.
- `README.md`, `index.html`, `llms.txt`, `robots.txt` and `sitemap.xml` describe or expose the skill. Keep their links and version in sync.
- `_site/` is generated by the Pages workflow and is never committed.

Publishing is `git push` to `main`; the Pages workflow validates, builds and deploys.

## Layout

- `SKILL.md` — canonical skill.
- `README.md` — human entry point and install instructions.
- `index.html` — static landing page with structured data.
- `assets/kizu-engineering-ai-toolkit.jpg` — canonical social preview image for GitHub and link sharing; keep it under 1 MB.
- `llms.txt` — AI discovery index; `llms-full.txt` is generated from `SKILL.md`.
- `robots.txt`, `sitemap.xml` — crawler guidance.
- `a9b09c5279e1ec7ae0f23c5fc9ae948b.txt` — IndexNow key file; keep it public and in the deployed site.
- `.github/workflows/pages.yml` — validation, catalog build, Pages deploy.
- `LICENSE` — MIT.

## Invariants

- No absolute paths, secrets, personal data or machine-only assets.
- Do not copy the skill text into other files. Generated copies are build artifacts only.
- The catalog version is `<release>+<sha256-prefix>` of `SKILL.md`; it is computed at build time, do not hardcode it.
- Keep the canonical URLs, snapshot date and release version consistent.
- Re-verify library versions before claiming they are current.

## Where to change

- Skill rules, versions, examples: `SKILL.md`.
- Install and usage instructions: `README.md` and `index.html`.
- Discovery metadata: `llms.txt`, `robots.txt`, `sitemap.xml`, GitHub topics.
